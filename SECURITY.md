# Reporting a security issue

Please use this repository's **Security → Report a vulnerability** option for vulnerabilities, exposed credentials or private data. Include affected paths, reproduction steps and impact without copying real secrets or personal information into a public issue.

Ordinary bugs and source-backed data corrections can use public issues. Do not post production access details, key files, credentials or sensitive case records.

The maintainer reviews reports before fixes are published. There is no guaranteed response time or paid bounty. For urgent platform abuse, use GitHub's reporting tools.
